# Вращающаяся крыса

3D-крыса, которая по факту вращается. Модель собрана кодом на Three.js, музыка синтезируется в браузере.

**Смотреть:** https://mrgreencheezz.github.io/spinning-rat/

## Управление

- тяни сцену мышкой — раскрутишь крысу сильнее
- `Пробел` — пауза, `R` — реверс, `M` — музыка, стрелки — скорость

## Локальный запуск

Открой `index.html` в браузере или запусти `node server.js` и зайди на http://localhost:4173.
